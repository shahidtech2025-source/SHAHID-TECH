SHAHID TECH Website Starter

Files:
- index.html : main website
- style.css  : design
- script.js  : sample forms, search and category filter

How to use:
1. Open index.html in a browser.
2. Replace "#" in script.js with verified official links.
3. Replace the YouTube "#" in index.html with your channel URL.
4. Upload all three files to your hosting.

Important:
This starter version does NOT have a secure admin panel or database.
Do not publish fake/unverified application links.
